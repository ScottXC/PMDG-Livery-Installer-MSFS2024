## Short description

Install and manage compatible third-party PMDG liveries for MSFS 2024. Browse a thumbnail library, search by airline or registration, review installs, export ZIPs, and restore complete package backups.

## Description

PMDG Livery Installer MSFS2024 is an independent Windows utility for compatible third-party PMDG aircraft liveries. Choose a ZIP or extracted folder, select an installed PMDG aircraft, review the destination and conflicts, and install into the matching companion livery package.

Version 0.1.6 rebuilds the interface with a dark sidebar, an original tail-fin icon, a thumbnail card library, clear installation steps, and dedicated details and diagnostics views.

### Features

- Browse installed liveries as cards or a list, with thumbnail previews and installed status.
- Search by aircraft, livery, airline, or registration; filter missing thumbnails.
- Select multiple liveries with Ctrl/Shift and export them to ZIP or uninstall them together.
- Detect Community folders and PMDG packages, then explicitly select the desired location and aircraft.
- Review recognized liveries, destination paths, sizes, and overwrite conflicts before installing.
- Prepare changes in a separate package copy, verify copied files and the generated layout, and keep a complete recovery backup when changing an existing package.
- Restore a previous whole-package backup or rebuild the companion package layout.
- Keep the interface responsive during scans and file operations; cancel at a safe stopping point.
- Diagnose package issues with PASS / FAIL / UNKNOWN results and export a report with personal paths hidden by default.

### Getting started

1. Extract the download and run `PMDG Livery Installer MSFS2024 Setup v0.1.6.exe`.
2. Open **Install liveries**, detect or browse to the Community folder used by MSFS 2024, and select the PMDG aircraft.
3. Choose a compatible ZIP or extracted livery folder.
4. Click **Review & Install**, check the destination and any conflicts, and confirm.
5. Open MSFS 2024 to check the livery in the simulator.

Use **My liveries** for browsing, search, export, uninstall, and backup restoration. Do not copy the utility itself into Community.

### Compatibility and scope

Requires Windows and an installed compatible PMDG aircraft for MSFS 2024. Includes mappings for the PMDG 737 family and 777-300ER; the source must match the actual aircraft/variant. No aircraft or third-party liveries are included. This independent utility is not affiliated with PMDG or Fenix.

PTP import, MSFS 2020 conversion, Fenix livery installation, and official account/download services are not supported. The file and GUI tests use synthetic packages; this v0.1.6 release has not been verified inside a real MSFS 2024 session. Recovery backups need additional disk space. Consult the included README before restoring a whole-package backup.
