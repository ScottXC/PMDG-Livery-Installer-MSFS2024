# v0.1.6 — Rebuilt livery library and recoverable installation

Browse installed liveries in a new thumbnail card grid, find them by airline or registration, and review the destination before installing. The interface takes navigation and browsing cues from OC3 and the Fenix Livery Manager, with original application and navigation icons.

## Changes

- Rebuilt dark sidebar and five pages: My liveries, Install liveries, Aircraft, Diagnostics, and Settings.
- Added installed-status cards, a separate details panel, Grid / List switching, keyboard selection, Ctrl/Shift multi-select, missing-thumbnail filtering, and 24-card pagination.
- Reorganized installation into source, aircraft/destination, and review. Preflight reports detected liveries, file size, conflicts, and the first source thumbnail before copying.
- Added staged package operations with SHA-256 copy verification, package-level locking, automatic rollback on handled failures, and complete recovery backups for existing packages.
- Added batch uninstall, ZIP export/reimport, full-package backup restoration, and verified companion-package layout repair.
- Moved scans, file operations, and thumbnail decoding off the GUI thread. Added cancellation at safe stopping points and a timeout for layout generation.
- Added actionable PASS / FAIL / UNKNOWN diagnostics and report export with personal paths hidden by default.
- Improved selection between multiple detected Community folders and rejection of explicitly mismatched aircraft variants.
- Updated application title, sidebar, Windows executable properties, installer, and release artifacts to v0.1.6.

## Downloads

- **Setup EXE:** installs the app for the current Windows user.
- **Flightsim.to ZIP:** Setup EXE, quick start, changelog, full documentation, and file checksums. This is the file to upload as the flightsim.to download.
- **Portable ZIP:** standalone application EXE and the same documentation. Extract it before running.
- **SHA256SUMS.txt:** checksums for the release downloads.

## Validation and limits

64 automated filesystem, Tk GUI, and release-privacy tests passed. The packaged executable also passed preflight, install, diagnostics, export, uninstall, restore, and layout-rebuild smoke checks using synthetic packages.

## Privacy packaging refresh

The v0.1.6 downloads have been refreshed after checking nested archives, installer metadata and embedded files, Python bytecode filenames, image metadata, and known build-machine identifiers. Machine-specific compiler paths and test usernames were replaced with discovery and generic fixtures. The application footer and Windows publisher field use generic project wording. Download ZIP metadata is normalized, and release packaging now fails if its privacy audit fails. Public GitHub project/support links remain available. Download the refreshed files and use the updated SHA-256 checksums if you have an earlier v0.1.6 copy.

Further Computer Use verification was skipped at the maintainer's request. This release has not been tested in a real MSFS 2024 session or revalidated under Proton. Use compatible MSFS 2024 PMDG ZIP/folder liveries; PTP import and MSFS 2020 conversion are not supported. The app does not install Fenix liveries or provide official aircraft/download services.

Full recovery backups consume disk space and are retained until removed. Restore replaces the entire companion livery package. The final pair of directory renames is not power-loss atomic; originals are retained in the recovery folder if interruption occurs between them. See README.md for recovery details.
